## Описание проекта
Проект представляет собой многостраничный сайт-энциклопедию «Серебряный век», посвященный литературному наследию поэтов рубежа XIX–XX веков. 

Изначально проект создавался по методическим указаниям для интернет-магазина. Поскольку предметной областью выбрана литература, **страницы были переименованы для соответствия контенту** (что является самостоятельной доработкой):
* `catalog.html` → **`alley_of_poets.html`** (каталог поэтов)
* `product.html` → **страницы поэтов** (`ahmatova.html`, `blok.html`, `esenin.html` и др.)
* `order.html` → **`subscribe.html`** (форма подписки на рассылку)

Все обязательные компоненты Bootstrap, требуемые в методических указаниях, реализованы в полном объеме на соответствующих страницах.

## Используемый фреймворк
Bootstrap 5.3.8.

## Способ подключения Bootstrap
Bootstrap подключён через **CDN (jsDelivr)**. 
Собственный файл `css/custom.css` подключён после Bootstrap для кастомизации внешнего вида.

## Реализованные обязательные компоненты Bootstrap
- **`navbar`** (единая навигация на всех страницах с закреплением `sticky-top`);
- **`card`** (карточки поэтов, карточки разделов на главной, карточки связей);
- **`btn`** (кнопки действий: «Подробнее», «Перейти», «Подписаться»);
- **`badge`** (метки литературных направлений: «Акмеизм», «Символизм», «Имажинизм»);
- **`alert`** (информационные сообщения, блок «Стихотворение дня»);
- **`modal`** (модальное окно «Редактору сайта» / «Сообщить о правке»);
- **`form-control`, `form-select`, `input-group`, `form-check`** (форма подписки `subscribe.html` и формы внутри модальных окон).

## Реализованные дополнительные компоненты Bootstrap
- **`accordion`** (хронология эпохи `timeline.html`, а также блоки биографий на страницах поэтов);
- **`tabs`** (вкладки литературных направлений `directions.html`);
- **`breadcrumb`** (хлебные крошки на страницах поэтов);
- **`table`** (таблицы ключевых событий на страницах поэтов).

## Самостоятельные доработки (повышенный уровень)
В ходе выполнения работы проект был существенно расширен сверх базовой инструкции:
1. **Расширение структуры:** вместо 4 базовых страниц создано **16 страниц** (добавлены разделы «Направления», «Хронология», «Связи поэтов», «Цитаты», «О проекте», а также персональные страницы для 9 поэтов).
2. **Собственный JavaScript (`js/main.js`):** 
   - разработан скрипт для динамического вывода «Стихотворения дня» (случайный выбор стихотворения и портрета автора на главной странице);
   - реализована логика плавной прокрутки наверх и появления кнопки «Наверх» (в виде пера).
3. **Глубокая кастомизация стилей (`css/custom.css`):**
   - разработана уникальная цветовая палитра в духе «старой бумаги» (`#f4f1ea`), заменяющая стандартные цвета Bootstrap;
   - подключены и настроены шрифты с засечками (`Playfair Display`, `PT Serif`);
   - добавлен эффект сепии для всех фотографий поэтов для создания винтажной атмосферы;
   - стилизованы все элементы интерфейса (кнопки, карточки, бейджи, формы, аккордеоны).
4. **Улучшенная форма:** форма подписки содержит `input-group` для email, `form-select` для выбора частоты и `form-check` для согласия на обработку данных.
